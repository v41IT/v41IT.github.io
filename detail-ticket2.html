Project Details

Project Overview

Implemented an automated malware detection and elimination system by integrating Wazuh SIEM with VirusTotal threat intelligence. The solution enables real-time file integrity monitoring on Linux endpoints, automatic scanning of suspicious files through VirusTotal, and an automation for immediate removal of confirmed threats.

Objectives

  • Establish File Integrity Monitoring: Monitor critical system directories including /etc/, /usr/bin/, /tmp/ for unauthorized changes.
  • Configure VirusTotal Integration: Connect Wazuh to VirusTotal API for cloud-based threat analysis on file hashes.
  • Deploy Active Response Script: Create automated malware removal script triggered when threat thresholds are exceeded.
  • Validate End-to-End Workflow: Test detection-to-remediation pipeline using EICAR test malware simulation.

Technical Architecture

  1. FIM Configuration: Real-time monitoring of sensitive directories (/etc/, /usr/bin/, /usr/sbin/, /tmp/) with recursive scanning and scheduled checks every 360 seconds.
  2. VirusTotal Integration: FIM detects file changes → Wazuh hashes file (MD5/SHA1/SHA256) → Query VirusTotal API → Alert generated if vendor detection count exceeds threshold.
  3. Active Response Script: Custom bash script receives file path from Wazuh, logs action to audit trail, removes file securely with safety checks to prevent deletion of critical system files.
  4. Validation Testing: Used EICAR test file to verify end-to-end detection-to-remediation automation without manual intervention.

Key Learnings

  • SIEM Configuration: Hands-on experience with enterprise-grade security monitoring infrastructure (Wazuh v4.x).
  • API Integration: Working with REST APIs for threat intelligence feeds (VirusTotal developer API).
  • Automation: Building self-healing security controls through bash scripting and Active Response framework.
  • Incident Response: Understanding the full kill chain from detection through containment and eradication.

Challenges Overcome

  • API Rate Limiting: Implemented caching and intelligent polling to stay within VirusTotal API quota.
  • False Positive Prevention: Added whitelist rules for trusted system updates and legitimate software installations.
  • Script Safety: Built path validation logic to prevent accidental deletion of critical OS files.
