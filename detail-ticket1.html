Wazuh SIEM Homelab: Endpoint Monitoring, FIM, and MITRE ATT&CK dashboard

Aug 2026

Deployed a Wazuh SIEM infrastructure in a virtualized homelab environment. Configured Ubuntu server, enrolled Windows 11 agent, implemented CIS Benchmark compliance auditing, File Integrity Monitoring (FIM) for registry tracking, and built a custom SOC Operations Dashboard for threat monitoring.

SIEM Wazuh Linux Windows SOC FIM

Project Details

Overview

After setting up my Wazuh homelab, I customized a SOC Operations Overview dashboard from scratch. This demonstrates how powerful Wazuh is as a tool for threat monitoring in a Security Operations Center context.

Architecture Components

  • Server: Ubuntu VM hosting the Wazuh platform
  • Agent: Windows VM with Wazuh agent for endpoint monitoring
  • Dashboard: Visualized security events, SCA, and File Integrity Monitoring

Key Features

  • Security Configuration Assessment (SCA): CIS Benchmark compliance monitoring, hardening recommendations, posture scoring
  • File Integrity Monitoring (FIM): Registry change detection, customizable scan rules, audit trail
  • Threat Hunting: Live event logs, detailed event inspection, application installation tracking
  • Custom SOC Dashboard: Color-coded severity alerts, alert counts, top threat source visualizations

Learning Outcomes

  • SIEM Fundamentals: Centralized log aggregation and correlation
  • Endpoint Monitoring: Deploying and managing agents across heterogeneous systems
  • Compliance Frameworks: Implementing CIS benchmarks for baseline security
  • Incident Investigation: Using threat hunting features for forensic analysis
  • Troubleshooting: Diagnosing network and configuration issues in security deployments

Challenges

  • Agent installation failed: Uninstalled/reinstalled Windows VM entirely
  • Connection refused: Verified IP alignment (ipconfig on Windows / ifconfig on Ubuntu)
  • Agent not registering: Reset IP with ipconfig /renew, removed stale agent from dashboard, re-ran deployment script
